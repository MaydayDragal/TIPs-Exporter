Choose an existing progress CSV from the list, or enter a new CSV filename. An existing file is loaded; a new file starts with your current browser progress.

Documents folder

Reading settings…

Select the parent containing your document folders (LI/GI), including any batch subfolders.

Manual and automatic updates request only indexed changes and missing files. Complete, unchanged documents are skipped. Older PDFs and attachments stay; changed files get versioned names. Use the Library screen to choose whether to download indexed documents missing from the folder.

In TIPS Exporter → Library, use Scan & verify for a local check against the loaded index. Sync now checks recent index changes, then saves the selected changes and gaps. Attachments are fetched only for changed or incomplete documents; an unchanged archive needs no TIPS requests during a folder update.

Scan & verify also records local attachment paths, sizes and modification times in the main index log, including nested attachments. It makes no TIPS requests. Missing or size-changed indexed files remain in the report. Known unavailable or unreadable PDF versions appear under Index errors and exceptions; routine updates skip them until you explicitly retry. New update errors are recorded automatically. All new PDFs, including PDF attachments, undergo required user-ID, download-date and metadata cleanup before saving.

Index changes and approved batch progress are saved automatically. Folder updates write directly into the documents folder; ZIP downloads use your browser's download location. Chrome may ask you to allow access again after restarting or installing another copy.
