Folders

Select the index log and your saved LI/GI archive. Future installations can select these same locations to continue.

Index folder

Reading settings…

Reload folder index replaces the browser's cached index and progress with the selected file. Use it to adopt changes from another installation.

Choose or change folder

Select a permanent folder outside the extension's installation folder.

Choose an existing progress CSV from the list, or enter a new CSV filename. An existing file is loaded; a new file starts with your current browser progress.

Documents folder

Reading settings…

Select the parent containing your document folders (LI/GI), including any batch subfolders.

New PDF versions are added beside saved versions. Older attachments stay; changed files get versioned names. Automatic updates only cover document folders already present.

In TIPS → Bulk export, use Scan & verify to compare the folder with the loaded index log, or Update saved documents to fetch missing versions and current attachments. The index log has no attachment manifest; attachments are checked against live TIPS during updates.

Index changes and approved batch progress are saved automatically. Folder updates write directly into the documents folder; ZIP downloads use your browser's download location. Chrome may ask you to allow access again after restarting or installing another copy.
